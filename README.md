# 🏥 Hospital Management System

## Overview

The Hospital Management System is a simple CRUD-based web application developed to manage patient records digitally.

The system allows hospital staff to add, view, update, delete and search patient information through an easy-to-use web interface.

## Objective

The main objective of this project is to develop a simple hospital management application that performs CRUD operations on patient records.

## Features

- Dashboard
- Add Patient
- View Patient Records
- Update Patient Details
- Delete Patient Records
- Search Patient
- Appointment Date
- Form Validation
- Responsive Design

## Patient Information

The system stores:

- Patient ID
- Patient Name
- Age
- Gender
- Phone Number
- Disease
- Doctor
- Appointment Date

## CRUD Operations

### Create
Add a new patient record.

### Read
View existing patient records.

### Update
Edit patient information.

### Delete
Remove a patient record.

## Project Workflow

1. User opens the Hospital Management System.
2. User enters patient details.
3. Patient information is stored in the database.
4. User can view patient records.
5. User can search for a patient.
6. User can update patient information.
7. User can delete a patient record.

## Expected Outcome

The project provides a simple and user-friendly software prototype for managing hospital patient records using CRUD operations.
